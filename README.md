# git-helper

A CLI tool that simplifies common Git workflows.

## Features

- Streamlined Git operations
- Workflow automation
- Easy-to-use command interface

## Installation

```bash
pip install git-helper
```

## Usage

```bash
git-helper <command> [options]
```
